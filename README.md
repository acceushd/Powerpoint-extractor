# Powerpoint-extractor
A program I am writing, inspired by [texstream](https://github.com/f/textream).  

My main purpose is to learn more of Rust, like the File I/O and different things.  
I wrote 100% of the code myself and am using AI only to help me understand the errors and how to fix them.  

## Technic things
The program is planned to be written entirely in rust.  
I am using the [zip](https://docs.rs/zip/latest/zip/), [itertools](https://docs.rs/itertools/latest/itertools/) and [tempfile](https://docs.rs/tempfile/latest/tempfile/) crates.  
I am writing with the 2024 version of Rust.  

## Rust
I am not that familiar with the syntax and conventions of Rust, so you will see a few Java conventions here and there
